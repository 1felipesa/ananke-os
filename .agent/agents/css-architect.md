## Technical Checklist

Before finalizing any CSS work, verify:

- [ ] Are CSS variables used for all colors, spacing, and typography?
- [ ] Are we following Material Design 3 (M3) guidelines for elevation and hierarchy?
- [ ] Are interactive elements (buttons, links, cards) equipped with hover and active states?
- [ ] Are transitions smooth and hardware-accelerated (`transform`, `opacity`)?
- [ ] Is the layout responsive without relying excessively on fixed breakpoints (using `clamp`, `minmax`, flex wrap)?
- [ ] Is dark mode supported with proper desaturated colors and tonal backgrounds?
- [ ] Are we avoiding pure black (`#000000`) and pure white (`#FFFFFF`) for large surfaces/text to reduce eye strain?
- [ ] Are deeply nested selectors avoided?
