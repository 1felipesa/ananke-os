# ✍️ Copy e Persuasão (Copy Workflow)

O comando `/copy` é o atalho para a criação de textos que convertem. Em vez de gerar texto genérico, este comando foca em gatilhos mentais, fluidez de leitura e direcionamento focado no usuário (UX Writing).

## Como Usar

Digite `/copy` seguido do formato do texto desejado e o objetivo.

**Exemplos:**
- `/copy Escreva uma Landing Page usando o framework AIDA para vender um curso de finanças.`
- `/copy Crie 3 opções de textos de anúncio (Facebook Ads) para uma clínica de estética com foco em desconto de verão.`
- `/copy Melhore os textos deste componente de Dashboard para ficarem mais curtos e focados na ação do usuário (UX Writing).`

## O que acontece por baixo dos panos?

1. O `copywriter-ux` é acionado instantaneamente.
2. Ele carrega as *skills* avançadas de Copywriting (frameworks como PAS, AIDA).
3. Produz um texto direto, estruturado em Markdown, com sugestões de tom de voz (urgência, autoridade, empatia) prontos para colar na interface ou nas campanhas.
